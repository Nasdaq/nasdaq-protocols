Installation¶

nasdaq-protocols requires Python 3.10+.

Install from PyPI¶

$ pip install nasdaq-protocols

Optional performance extras¶

For improved async throughput, install with the performance extra. This pulls in uvloop (Linux/macOS only), which provides ~4-5x faster event loop scheduling:

$ pip install nasdaq-protocols[performance]

Activate it early in your application, before any asyncio work:

from nasdaq_protocols.common import use_fast_loop
use_fast_loop()

If uvloop is not installed, use_fast_loop() is a no-op.

Setting up a development environment¶

This project uses uv for dependency management, building, testing, linting and docs. Clone the repo and run:

$ uv sync --group dev

See the Developer’s Guide for the full contributor workflow.
